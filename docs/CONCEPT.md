# 九境 Ninefold — concept

**This document was folded into the bible and is no longer maintained.**

It described the game as it was agreed on 19 September 2026: the loop, the nine realms,
the beasts, the curve, the art direction, and what was out of scope for a first version.
Every one of those sections now lives in `bible.html`, generated by `tools/bible.ts` and
republished to the artifact — with the difference that the bible reads its numbers out of
the game's own code on every build, so it cannot drift from what the game does.

A second description of a game is a second thing to keep true, and this one had been
wrong for two days before anybody noticed. The old text is in the history if it is ever
wanted: `git log -- docs/CONCEPT.md`.

**Read the bible.** `npm run bible` writes it; the board at the top of it says what is
built, and every section below says how and why.
